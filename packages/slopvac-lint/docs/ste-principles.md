# Drafting principles

Hold these while writing. The linter owns mechanical substitutions, configured vocabulary checks, and length checks. The principles below are the habits that shape a sentence before the linter runs.

1. Give one idea per sentence. If you can split it at a clause boundary without loss, split it.
2. Give one instruction per step. A step with a second action gets half done.
3. Cap an instruction at 20 words and an explanation at 25. Count a number with its unit, a quoted span, and a hyphenated compound as one word each.
4. Name the actor as the subject. Write what a thing does, not what is done to it.
5. Use one word for one meaning, and one name for one thing. Never vary a term for elegance.
6. Put the action in the verb. A verb plus a noun naming that same action is one word too many.
7. State the condition first. Follow it with the command.
8. Open a safety block with the command. State the consequence next. Keep the first line clear about what to avoid.
9. Name the thing rather than pointing at it. A sentence that opens with a bare "this" or "these" makes the reader look backward.

Then run the linter. It reports mechanical findings with source locations. A rule includes a replacement when it can determine one safe edit. Fix the named defect rather than re-reading this list.
