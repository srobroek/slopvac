# Support

Start with the [project README](README.md) for installation, use, and agent setup. The [Slopvac CLI reference](packages/slopvac-lint/README.md) and [`packages/slopvac-lint/docs/`](packages/slopvac-lint/docs/) cover commands, configuration, rules, and finding triage.

For a problem or rule proposal, choose a form at [New issue](https://github.com/srobroek/slopvac/issues/new/choose). The forms cover bugs, false positives, missed slop, mis-tagged findings, wrong fixes, new rules, and rule improvements. Agents must run `slopvac prime report` before filing. Agents must get the user's approval for the exact post. This project does not use GitHub Discussions.

For a security vulnerability, use the private reporting instructions in [`SECURITY.md`](SECURITY.md). Do not disclose vulnerabilities in public issues.
